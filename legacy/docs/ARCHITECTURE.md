## 核心算法

### 1. 动量因子
```
Momentum(t) = [P(t-21) / P(t-273)] - 1

其中：
- P(t) = 复权收盘价
- 252天 = 12个月
- 跳过21天 = 1个月
```

### 2. IC计算
```
IC(t) = Spearman_Corr(factor_scores_t, forward_returns_t)

有效标准：
- IC_mean > 0.02
- IC_t_stat > 2.0
- IC_positive% > 60%
```

### 3. 均值-方差优化
```
maximize: w^T μ - λ × w^T Σ w

subject to:
- Σ w_i = 1
- w_i ≥ 0
- w_i ≤ 0.05
- Σ |w_i - w_prev| ≤ 0.5

其中：
- w = 权重向量
- μ = 预期收益（因子得分）
- Σ = 协方差矩阵（Ledoit-Wolf估计）
- λ = 风险厌恶系数（默认1.0）
```

### 4. 绩效指标
```
Sharpe = (年化收益 - 无风险利率) / 年化波动率

Max DD = max_t [(峰值_t - 谷值_t) / 峰值_t]

Calmar = 年化收益 / |最大回撤|

Turnover = Σ |w_new - w_old|
```

## 性能优化

1. **缓存策略**
   - Parquet格式（比CSV快10倍）
   - Snappy压缩（减少50%磁盘占用）
   - 7天自动过期

2. **并行处理**
   - ThreadPoolExecutor（5 workers）
   - 批量下载（50只股票/批）

3. **速率限制**
   - 智能限流（2000 req/hr）
   - 自动重试（3次，间隔5秒）

4. **向量化计算**
   - pandas pivot操作
   - numpy矩阵运算
   - 避免循环

- **CPU**: 2+ 核心

- **数据下载**: 50只股票/分钟
- **因子计算**: <1秒（100只×1000天）
- **组合优化**: <1秒（20只股票）
